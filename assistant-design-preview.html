Design review

Why the assistant feels “bolted on” — and 4 fixes

The widget ships its own luxury palette (teal / forest green + antique gold) with serif headings, while the clinic site is navy + sky-blue with soft gold as a small accent. Two different hue families, two different golds, two different type systems — that is what the eye reads as “not matching”.

Every option below is a pure palette swap: same layout, same SVG character, same behaviour — only the colours (and, in A–D, the typeface) change. Open in full screen, and toggle dark mode top-right.

Current

What is live today

Teal header, greenish-grey bubbles, beige info card, serif headings. On a blue page it reads as a different product — and in dark mode it turns teal-black while the site turns navy-black. “Current” is shown without its animation so it can be compared fairly.

Option A

Brand Blue

Recommended

Blue does the heavy lifting — navy header, blue-gradient buttons and user bubble exactly like the site’s .btn, pale-blue bot bubble and card from the site’s --tint. Gold shrinks to a refined accent (avatar ring, AI badge, mic) which is exactly how the site uses gold. Plus Jakarta Sans everywhere.

Option B

Gold Signature

Same blue skeleton, but gold is promoted to the signature: gold call-to-action buttons, gold-hairline under the navy header, gold-outlined chips and a warm cream card (the same treatment as the site’s “Most popular” tier). Navy stays the base so it still reads as one brand.

Option C

Midnight Concierge

Bold

A deliberately premium departure: the panel stays dark navy even on the light site (like a concierge desk), with gold CTAs and a navy-blue gradient for the user. It is the most “luxury” of the four, but it no longer matches the light site surfaces — pick this only if the client wants the chat to feel like a separate VIP service.

Option D

Clean Clinical

Gold removed entirely — blue and sky-blue only. The calmest, most medical option: pale-blue accents, blue avatar ring, white chips. Safest for a clinic that wants zero decorative colour, though you lose the warm gold that makes the site feel premium.

Notes

What stays the same in every option

Layout, sizes, spacing, the SVG character, the mic / voice logic and all behaviour are untouched — this is a palette + typeface change only, so nothing breaks and there is no re-testing of flows. The character illustration is recoloured the same way in each option (scrubs become navy, accessories use the site gold) and lists are rendered with the same code path.

Accessibility: bot text is #5B6B7F on #FFF (5.2:1), user bubble white on the blue gradient stays ≥ 4.8:1, and the focus ring becomes the site’s 3px blue outline. Option A also lets us delete the Google Fonts import (Cormorant + Manrope) since Plus Jakarta Sans is already self-hosted.
